# Seblak Telor Mas Iman

Landing page statis untuk Seblak Telor Mas Iman. Dibuat menggunakan HTML, CSS, dan JavaScript tanpa framework.

## Fitur
- Menu dan harga berdasarkan jumlah telur
- Informasi level pedas
- Lokasi dan tautan Google Maps
- Jam operasional serta pengingat untuk mengecek WhatsApp Story
- Layout responsif untuk ponsel dan desktop

## Deploy dengan GitHub Pages
1. Buka **Settings → Pages**.
2. Pada **Build and deployment**, pilih **Deploy from a branch**.
3. Pilih branch **main** dan folder **/(root)**, lalu klik **Save**.
4. Tunggu proses publikasi selesai.

URL yang diharapkan: https://rajuamardev.github.io/seblak-mas-iman/

## Catatan aset
Folder assets berisi ilustrasi SVG sementara. Ganti assets/seblak.svg dan assets/gerobak.svg dengan foto asli usaha jika ingin memakai foto yang dikirim pemilik. Sesuaikan path gambar di index.html bila format file berubah.

Informasi operasional dapat berubah. Website mengarahkan pengunjung untuk mengecek WhatsApp Story sebelum datang dan tidak mengklaim status buka real-time.
